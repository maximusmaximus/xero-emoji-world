# World record

Inference that changes the city is stored in two places:

- The app database, tables `world_state` (the city) and `world_changes` (one row per story or development).
- This folder. `state.json` is the city after the latest live call. `changes.jsonl` is the log.

The host Venice key spends one dollar a day, then waits until the next midnight in America/Los_Angeles. A pasted key keeps the city growing until that reset. Keys are never written here.
